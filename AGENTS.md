# Architecture rules

- Use the shared additional-category checklist for product creation and editing, keeping selections as an array compatible with existing catalog filtering and writes.

- Keep product image frames responsive and use contain fitting across catalog, gallery, and cart views so uploaded photos are never distorted or cropped.
- Normalize new product uploads to the configured square resolution using proportional scaling and transparent letterboxing so every upload retains its complete composition.
- Compose homepage editorial collections in a dedicated module using public catalog reads with category-photo fallbacks, so empty catalogs remain presentable without inventing products.
- Scope editorial styles and scroll reveals to the four Gary Edit/philosophy sections; use contain-fitted photos with protected inner gutters so decoration cannot obscure footwear or affect neighboring sections.
